# План пилота

Проверяем, помогает ли чат знакомства быстрее найти наставника и его контакт.
Пилот не проведён; результатов пока нет.

1. Подготовить одинаковые сведения о команде и эталонный ответ.
2. Случайно разделить стажёров на две группы: обычные материалы и чат AI-buddy.
3. Дать одинаковое задание и ограничение по времени.
4. Записать время, ответ и случаи, когда ответ не найден.

Сравнить время до правильного ответа, долю ошибок и долю завершивших задание.
Ожидаемый результат: время уменьшается без роста ошибок и снижения доли завершения.
